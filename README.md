# Редактор модов «Проклятых Земель» (Evil Islands)

Это редактор в браузере для всего, что есть в игре: карт, рельефа, объектов и существ, маршрутов патрулей, скриптов, предметов, магии, квестов, диалогов, текстов, моделей и текстур.

## Запуск

1. Нужен [Node.js](https://nodejs.org) версии 18 или новее.
2. Дважды щёлкните **`Запустить редактор.bat`**. Редактор откроется в браузере по адресу http://127.0.0.1:8765. Окно консоли не закрывайте, пока работаете.
3. Редактор ищет игру в папке `../Evil Islands`. Если игра лежит в другом месте, создайте файл `config.json` с таким содержимым:

   ```json
   {"gameDir": "C:/Games/Evil Islands"}
   ```

Редактор сохраняет изменения прямо в файлы игры. Перед первым изменением файла его оригинал копируется в `backup/`. Кнопка **«Вернуть оригиналы»** на главной вернёт игру в исходное состояние и удалит файлы, которые создал редактор.

## Разделы

| Раздел | Что умеет |
|---|---|
| Карты и ландшафт | 3D-вид зоны с текстурами и моделями. Объекты и существа можно выбирать, двигать (W) и вращать (E), копировать (Ctrl+D) и удалять (Del). Существо добавляется из базы, модель и текстура подставляются по его расе. Можно редактировать снаряжение, маршрут патруля (точки на карте), высоту рельефа (поднять, опустить, сгладить, выровнять), тайлы земли с поворотом и скрипт карты. |
| Предметы, существа, магия | Все таблицы `database.res` и `databaselmp.res`: оружие, доспехи, материалы, зелья, монстры, НПС, расы, заклинания, перки, рычаги, награды квестов. Записи можно дублировать и удалять. |
| Квесты и диалоги | Квесты (название, описание, подзадачи) и брифинги (реплики персонажей, камера, порядок). Для сетевых квестов `.mq` здесь же редактируется `quest.reg`: награды и выдаваемые квесты. |
| Острова и зоны | Глобальная карта по `map.txt`: зоны, переходы, правка блоков. Мастер новой зоны создаёт `.mpr`, `.mob`, текстуры, запись в карте мира и переход из соседней зоны. |
| Все тексты игры | `texts.res` и `textslmp.res`: поиск, правка, новые записи. |
| Модели и анимации | Все 452 модели из `figures.res` с текстурами, телосложением и проигрыванием анимаций. **Импорт своих моделей из OBJ** (Blender, 3ds Max и др.) с текстурой PNG/JPG: предпросмотр, затем «Сохранить в игру». Каждый объект `o`/`g` в OBJ становится частью модели. |
| Текстуры | Просмотр, экспорт в PNG, замена своей картинкой. |

## Что проверено и что нет

Команда `npm test` проверяет все форматы на файлах игры. Каждый файл читается и записывается обратно:

- **Совпадают байт-в-байт:** все 99 `.mob`, все таблицы БД, сектора всех 38 `.mpr`.
- **Совпадают по содержимому:** все записи RES, все `.reg`.
- **Модели:** все 3124 меша FIG и все BON пересобираются байт-в-байт; 948 анимаций читаются.
- **Просто читаются:** все 3700 текстур.

Ещё проверены через интерфейс правка цены, перемещение существа, точка патруля, новое существо и новая зона. Изменения записались в файлы, а откат вернул оригиналы.

**Внутри игры правки не проверялись.** Перед большим модом сделайте маленькую правку и запустите игру.

Известные ограничения:

- **Проходимость (AI-граф).** Формат разобран полностью (см. ниже). Оригинальный граф сохраняется, а при сохранении карты пересчитываются только участки вокруг изменённого рельефа и перемещённых, добавленных или удалённых объектов. Новая зона получает граф целиком. Правила построения подобраны по оригинальным картам и совпадают с графом Nival на 84–91% переходов, поэтому на изменённых участках существа могут ходить чуть иначе, чем в оригинальной игре. Кнопка «◍ Проходимость» на карте показывает граф для выбранного класса существ.
- **Новый остров.** Он добавляется как новый `allod` в `map.txt`, но для глобальной карты нужны свои фигуры. Проще начинать с новых зон на существующих островах.
- **Модели.** Импорт из OBJ даёт статичные модели — для строений, деревьев, предметов на карте. Существа с анимацией по-прежнему делаются в Blender с аддоном `ei_figer` из папки `Files`. Импортированная модель пока не проверялась в самой игре, только в редакторе.
- **Акустика и частицы.** Звуки (`cc01`), свет (`aa01`) и частицы (`dd01`) на карте сохраняются как есть, но отдельных форм для них нет.

## ИИ-помощник (MCP)

`mcp.js` — MCP-сервер, через который ИИ (Claude Code, Claude Desktop и другие) пользуется всеми функциями редактора: создаёт зоны, лепит и раскрашивает рельеф, расставляет существ и объекты, задаёт патрули, правит скрипты, базу, тексты, квесты, модели и текстуры. Правки защищены теми же бэкапами. Подключение и полное руководство для ИИ — в [MCP.md](MCP.md). Самопроверка на копии игры: `npm run test:mcp`.

## Для разработчиков

- `src/formats/*.js` — чтение и запись форматов без зависимостей, работают и в Node, и в браузере:
  - `res`: архивы;
  - `reg`: конфиги;
  - `db`: база по схеме `data/dbschema` из EIDBEditor (LGPL);
  - `mob`: объекты карт, патрули, шифрованный скрипт;
  - `mpr`: ландшафт;
  - `mmp`: текстуры DXT1/DXT3/PNT3/8888/565/4444/1555;
  - `fig`: модели FIG8, LNK, BON (чтение и запись), ANM;
  - `obj`: конвертер Wavefront OBJ в части модели;
  - `aigraph`: граф проходимости — чтение, запись, построение по правилам, частичный пересчёт.
- `server.js` — локальный сервер. Слушает только 127.0.0.1 и не пускает за пределы папки игры.
- `src/game.js` — доступ к папке игры, бэкапы и откат (общий для `server.js` и `mcp.js`); `src/shared/` — логика без DOM для браузера и MCP (мастер зон, каталог объектов).
- `mcp.js` — MCP-сервер (stdio); `tools/mcp-test.mjs` — его проверка.
- `public/` — интерфейс: ES-модули без сборки и three.js.

Особенности форматов, найденные при разработке:

- Z у объектов и существ в `.mob` — это высота над землёй. Точки патруля хранят абсолютную высоту.
- Атласы земли хранятся перевёрнутыми по вертикали, тайлы поворачиваются по часовой стрелке. Это установлено по стыкам цветов между соседними тайлами.
- В PNT3 слово 0 или больше 1 000 000 — это пиксель BGRA, остальные значения — пропуск такого числа нулевых байт.
- Граф проходимости (чанк `0x31415926` в конце `.mob`, у zone6 — файл `zone6.grp`):
  - заголовок `u32 W, u32 H` — по 8 узлов на сектор, узел 4×4 м;
  - 8 слоёв — AI-классы рас из базы (0 летающие, 1 мелкие звери, 2 гоблины, 3 люди и орки, 5 ящеры и скелеты, 6 огры и големы, 7 тролли и циклопы);
  - строка слоя: W×8 `u16` стоимостей перехода к соседям (0 = −y, далее против часовой; `0xFFFF` — прохода нет; 16 на метр для класса 0, 32 для остальных), затем W байт точки привязки (полубайты y/x с шагом 0,5 м, `0x33` — центр), затем W `u16` номеров связных областей (с 1 по порядку обхода).
  - `tools/aigraph-fit.mjs` замеряет совпадение построения с оригиналом и подбирает пороги, `tools/aigraph-probe.mjs` рисует слои ASCII-картой.
